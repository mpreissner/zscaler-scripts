The "Zscaler Tunnel" adapter created by VPN for Legacy Apps can sometimes be classified by Windows as a
"Public" network profile, which drops all incoming connections by default.  These instructions, along
with the ZVPN-ConProf.ps1 script allow the endpoint to automatically ensure the adapter gets classified
as a "Private" network connection, with which Windows Firewall is more permissive (allows certain incoming connections).

Store the ZVPN-ConProf.ps1 file on a universally accessible file share such as \\yourdomain.com\SYSVOL\yourdomain.com\scripts\ZVPN-ConProf.ps1

Create a GPO per the following. These can be deployed together in a single GPO or as separate GPOs

Computer Configuration > Preferences > Windows Settings > Files
Right click Files, select New > File
Action: Update (or Create)
Source File(s): <network share path where script is stored, such as on SYSVOL indicated above>
Target File: C:\ProgramData\Scripts\ZVPN-ConProf.ps1


Create a scheduled task and deploy via GPO to all users with the following configurations
Computer Configuration > Preferences > Control Panel Settings > Scheduled Tasks
Create a task for Windows Vista and later

General Tab
Name: ZVPN Network Connection Profile config
Run whether user is logged on or not
Run with highest privileges
User account: SYSTEM # (or NT AUTHORITY\SYSTEM)

Trigger Tab
Begin the task: On an event
Log: Microsoft-Windows-NetworkProfile/Operational
Source: NetworkProfile
Event ID: 10000

Actions Tab
Action: Start a program
Program/script: powershell.exe
Add arguments: -NoProfile -ExecutionPolicy Bypass -File "C:\ProgramData\Scripts\ZVPN-ConProf.ps1" # Recommended path, deploy script via GPO. Set path as appropriate.

Conditions Tab
Uncheck "Start the task on if the computer is idle for:"
Uncheck "Start the task only if the computer is on AC power"
Uncheck "Wake the computer to run this task"
Uncheck "Start only if the following network connection is available"

Settings Tab
Check "Allow Task to be run on demand"
Check "Run task as soon as possible after a scheduled start is missed"
Uncheck "If the task fails, restart every:"
Check "Stop the task if it runs longer than:" and set to 1 hour # Script should exit in under 1 second so not likely to ever fire
Check "If the running task does not end when requested, force it to stop
Uncheck "If the task is not scheduled to run again, delete it after:"
Set "If the task is already running, then the following rule applies:" to "Do not start a new instance"
